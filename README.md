# TAS – Releases

Hier liegen nur die fertigen Installations- und Update-Dateien von TAS für macOS.
Der Quellcode ist privat.

**Installation:** Beim neuesten Release `TAS-osx-Setup.pkg` herunterladen und öffnen.
Beim allerersten Start: Rechtsklick auf TAS → „Öffnen“ (die App ist nicht über ein
Apple-Entwicklerkonto signiert).

**Updates:** TAS prüft beim Start selbst, ob hier ein neues Release liegt, und bietet
„Jetzt aktualisieren“ an.
